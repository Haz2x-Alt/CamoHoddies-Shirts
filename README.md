# Camo Hoodie
Website https://haz2x.netlify.app/#
*Camo Hoodie* is a custom cosmetic created for [Gorilla Tag](https://gorillatagvr.com/) using *GorillaShirts*. The hoodie features a camouflage design intended to give players a unique and recognizable appearance while playing.

## Usage

*Camo Hoodie* is designed to be used through *GorillaShirts*. Once the shirt is installed, it can be equipped through the GorillaShirts Shirt Stand in-game.

The hoodie is intended to work with the GorillaShirts cosmetic system and can be worn alongside the features provided by the mod.

## Features

*Camo Hoodie* includes a custom hoodie design created specifically for Gorilla Tag.

* **Camo Design**
  A custom camouflage pattern covering the hoodie.

* **Hoodie Cosmetic**
  A hoodie-style cosmetic designed to fit the Gorilla Tag gorilla character.

* **GorillaShirts Support**
  Created for use with the GorillaShirts custom cosmetic system.

* **Babe**
  Created and designed by **Babe**.

## Installation

To use *Camo Hoodie*, you must have [GorillaShirts](https://github.com/SakuraaDevelopment/GorillaShirts-BepInEx) installed and configured.

After obtaining the Camo Hoodie files, place them according to the installation instructions provided with the corresponding GorillaShirts release.

Once installed, launch Gorilla Tag and locate the shirt through the GorillaShirts Shirt Stand.
